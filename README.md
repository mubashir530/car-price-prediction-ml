# 🚗 Car Price Prediction using Machine Learning

An end-to-end Machine Learning project to predict used car prices based on features like vehicle age, mileage, fuel type, transmission, and brand history. Multiple regression models were trained and evaluated, with **Random Forest Regressor** delivering the highest accuracy and lowest prediction error.

---

## 📊 Key Highlights & Results
- **Best Model:** Random Forest Regressor
- **Evaluation Metrics:** R² Score, Mean Absolute Error (MAE), Root Mean Squared Error (RMSE)
- **Key Outcome:** Random Forest outperformed baseline linear models by effectively capturing non-linear relationships and feature interactions within the dataset.

---

## 🛠 Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
- **Environment:** Jupyter Notebook / VS Code

---

## 📈 ML Workflow
1. **Data Cleaning & Preprocessing:** Handling missing values, removing outliers, and encoding categorical variables.
2. **Exploratory Data Analysis (EDA):** Visualizing feature correlations and price distribution across different car brands and models.
3. **Model Training & Comparison:** Trained Linear Regression, Decision Tree, and Random Forest algorithms.
4. **Hyperparameter Tuning:** Fine-tuned the Random Forest Regressor to improve prediction accuracy and prevent overfitting.
